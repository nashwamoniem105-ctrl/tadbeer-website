# موقع شركة تدبير للاستقدام (نسخة مستقلة)

تم بناء هذه النسخة لتكون مستقلة تماماً عن أي روابط خارجية أو خدمات CDN، مما يضمن عملها بشكل دائم وسريع.

## الميزات
- **نظافة كاملة:** لا يوجد أي اتصال بمواقع خارجية (Google Fonts, CDNs, etc).
- **لوحة تحكم (Admin):** لمتابعة طلبات العملاء التي تصل من الموقع.
- **قاعدة بيانات:** مرتبطة بـ PostgreSQL لحفظ البيانات بأمان.
- **جاهز للنشر:** مهيأ للعمل مباشرة على Railway أو أي منصة تدعم Docker.

## روابط الوصول
- **الموقع:** [https://tadbeer-website-production.up.railway.app](https://tadbeer-website-production.up.railway.app)
- **لوحة الأدمن:** `/admin`
- **كلمة مرور الأدمن:** `tadbeer-admin-2026`

## ملاحظات تقنية
- تم استبدال جميع الروابط الخارجية بمسارات محلية.
- تم بناء API بديل لمعالجة طلبات المحتوى والبيانات.
- الطلبات تُحفظ في جدول `leads` في قاعدة البيانات.

تم التنفيذ بواسطة Manus AI.
